## VER-1 Verification log

- Group runs by `(Class, Cmd)` in order of first appearance.
- Finding per group: `` `{cmd}` ×{n} ({statuses joined by ", "}) — last: {counts} `` where
  statuses are `pass`/`fail`/`unknown` per run (show at most the last 6,
  prefixed `…, ` when truncated) and counts is `{P} passed, {F} failed` when
  parsed, else `{status}`. Severity `alert` when the group's last run failed,
  else `info`. Evidence: the last run (excerpt = last 200 chars of output).
  Data: `{"class","runs","last_status","by_user": bool}`.
- Summary: `Checks ran {N} times: {class} ×{n} (last {status}), …` over classes
  in the order test, typecheck, lint, build. None: `No test, lint, typecheck or build commands ran.`
- State: `alert` if any group's last run failed; `info` otherwise.
- Data: `{"runs":[{"class","cmd","session","event","ts","status","passed","failed","skipped","by_user"}], "by_class": {class: {"runs": n, "last": status}}}`.

## VER-2 Verification freshness

Definitions:
- **Shaping events** `S`: events that are the `Source` of at least one PR line
  labeled `agent`, `agent_then_human` or `human_in_session` in `c.Attribution`.
- **Reference class**: `test` if any test run exists; else the first of
  `typecheck`, `build`, `lint` that has runs.
- **Last pass**: the latest run of the reference class with `Result.Status == "pass"`.

Cases, in order:
1. No sessions → `NoSessions`.
2. `S` empty → `Unknown("No PR lines came from captured sessions.")`.
3. No check runs at all → State `alert`, Summary
   `No test, lint, typecheck or build ran after the agent's edits in any captured session.`
   One finding per PR file that has shaping lines (max 20), anchors from
   `c.AnchorsFor` of that file's shaping events, severity alert,
   summary `` `{file}` was never checked in a captured session. `` Data `{"never_verified": true}`.
4. Reference class has runs but none passed → State `alert`, Summary
   `No passing {class} run in captured sessions; the last one failed at {Clock}.`
   One finding with evidence on that run.
5. Otherwise let `stale` = shaping events with `TS` after the last pass.
   - `stale` empty → State `clear`, Summary
     `` The last passing {class} run (`{cmd}`, {Clock}) came after every captured edit to PR lines. ``
   - else State `alert`, Summary
     `{h} PR hunks were edited after the last passing {class} run ({Clock}).`
     where `h` = number of anchors from `c.AnchorsFor(stale...)`.
     Findings: one per file (file order), `` `{file}` lines {ranges} changed at {Clock of latest stale edit}, after the last passing run. ``
     anchors = that file's anchors; evidence = the stale edits in that file
     (max 3) plus, on the first finding only, the last-pass run.
6. If `c.Attribution` has any `uncaptured` lines, add an `info` finding:
   `{u} changed lines were written outside captured sessions, so when they were written relative to checks is unknown.`

Data: `{"class", "last_pass": {"session","event","ts","cmd"} | null, "stale_events": n, "stale_hunks": h, "never_verified": bool, "uncaptured_lines": u}`.

Use the timeline order (not per-session order): a test run in a Codex session
after a Claude Code edit counts.
