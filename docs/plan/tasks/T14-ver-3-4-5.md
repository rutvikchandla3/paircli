## VER-3 Check-to-change coverage (heuristic)

- Changed source files: PR files with ≥1 added line whose classes (from
  `classify.Path`) include none of `test`, `docs`, `generated`, `lockfile`,
  `manifest`, `ci_config`, `snapshot`.
- Test runs: check runs with class `test`. None → `Unknown("No test runs to compare against.")`.
- Targeted arguments of a run: tokens after the runner that contain `/` or
  end in a code extension (`.go .ts .tsx .js .jsx .mjs .cjs .py .rb .rs .java .kt .cs .php .swift .ex .exs`),
  plus Go package patterns (`./x/...`, `./x`). Strip pytest node ids (`::…`)
  and a leading `./`. A run with no targeted arguments is a **full-suite** run.
- Any full-suite run → State `clear`, Summary `` A full test run (`{cmd}`) ran; every changed file was likely exercised. ``
- Else a changed file `F` is *likely covered* when some targeted arg `A`:
  (a) `F` starts with `A` treated as a directory (Go `./pkg/...` → `pkg/`);
  (b) `F` and `A` share their first two path segments; or
  (c) `F`'s base name without extension appears in `A`'s base name (`retry.ts` ↔ `retry.test.ts`).
- Uncovered files → State `info` (never alert: this is a heuristic),
  Summary `Likely not exercised by any test run: {k} changed files (e.g. `{first}`).`
  Finding per file (max 20): `` `{file}` — no targeted test run matched it (likely). `` anchors `{File: file}`.
- All covered → `clear`, `Every changed source file matched a targeted test run.`
- Data: `{"uncovered":[…], "targeted_runs": n, "full_suite": false}`.

## VER-4 Test integrity

Collect findings from all rules; State `alert` if any, else `clear` with
`No weakened tests, new skips, snapshot rewrites or deleted tests found.`

1. **Edited between fail and pass.** For each failing test run `F`, let `P` be
   the next passing test run after it (timeline). Agent `file_edit` events
   (not failed) between them on paths classified `test` → one finding per `F`:
   `` Test file `{file}` was edited between a failing run ({Clock F}) and the next passing run ({Clock P}). ``
   If those edits removed more assertion-like lines than they added
   (`classify.AssertionLike` over `Removed` vs `Added`), append
   ` It lost {n} assertion lines.` Anchors: `c.AnchorsFor(edits…)`; fallback `{File}`.
   Evidence: F, the edits (max 2), P.
2. **Assertions removed in the PR.** For each PR file classified `test`: removed
   assertion-like lines minus added assertion-like lines ≥ 1 →
   `` `{file}`: {r} assertion lines removed, {a} added. `` anchor `{File}`.
3. **Skip/only markers added.** Added lines with `classify.SkipMarker` →
   `` `{file}:{line}` adds a `{kind}` marker: `{Clip(trimmed line, 60)}` `` anchor at that line.
   Evidence: the attributed source event when the line has one.
4. **Snapshot updates.** Commands classified `snapshot_update` → `` Snapshots regenerated with `{cmd}` at {Clock}. `` ;
   PR files classified `snapshot` that are modified or added → `` Snapshot file changed: `{file}`. ``
5. **Deleted tests.** PR files with status `deleted` classified `test` → `` Test file deleted: `{file}`. ``

Data: `{"fail_edit_pass": n, "assertions_removed": n, "skip_markers": n, "snapshot_updates": n, "deleted_tests": n}`.

## VER-5 Quality-gate bypasses

Findings (all severity `alert`); State `alert` if any, else `clear` with
`No skipped hooks, new suppressions, or CI/coverage config changes.`

1. Commands with class `no_verify` or `hook_skip_env` → `` Commit made with `{cmd}`{suffix}. `` where
   suffix = ` after the pre-commit hook failed` when the previous `git_commit`
   command in the same session, within 10 minutes, failed. Evidence on both.
2. Suppression comments added: per PR file (skip `generated`), added lines with
   `classify.Suppression` → `` `{file}` adds {n} suppressions ({distinct kinds}). ``
   anchors at those lines.
3. CI config changed: PR files classified `ci_config` → `` CI config changed: `{file}`. ``
4. Coverage thresholds: in PR files whose base name matches
   `^(jest|vitest|karma)\.config\.|^\.coveragerc$|^setup\.cfg$|^pyproject\.toml$|^codecov\.ya?ml$|^\.nycrc`,
   any added or removed line matching `(?i)(coverageThreshold|fail_under|cov-fail-under|\b(branches|lines|functions|statements)\s*:)`
   → `` Coverage threshold changed in `{file}`. `` anchor file.

Data: `{"no_verify": n, "suppressions": n, "ci_config": n, "coverage_config": n}`.
