## `BuildReport(in)`

- `SchemaVersion: model.SchemaVersion`, `GeneratedAt: in.Now.UTC()`, `Tool: "paircli " + in.Version`.
- `PR`: fields from `in.PR`; `Commits`, `Files` counts; `Additions`/`Deletions`
  = total added/deleted diff lines.
- `Coverage`: `Sessions` = len(in.Sessions); `Harnesses` counts; `Capture`:
  `none` (no sessions), `hooked` (all hooked), `reconstructed` (none hooked),
  else `partial`; lines and ratio from `in.Attribution`;
  `UnattributedCommits` = `in.Unattributed` (never nil: use `[]string{}`);
  `DroppedSessions` = `in.Dropped`.
- `Sessions`: one `SessionSummary` per session in input order: `Ref`, `Harness`,
  `ID`, `Title`, `Start`, `End`, `Models` (distinct non-empty `Event.Model`
  in order of first appearance), `Capture`, `Link` (`in.SessionLinks[ref]`,
  default `none`), `Commits` (SHAs of `in.Links` that list the ref), `SourcePath`
  (through `engine.Home`), `Counts` by kind, `Usage` summed over `Message.Usage`,
  `LinesAuthored` = attribution lines whose `Source.Session` is the ref.
- `Commits` = `in.Links`; `Signals` = `in.Signals` (already in catalog order).

## `Write(opts, rep, attr, sessions)`

`MkdirAll(opts.OutDir/sessions)`; delete existing `*.json` directly inside
`sessions/`; write, each with a trailing newline:
- `signals.json` — `json.MarshalIndent(rep, "", "  ")`
- `report.md` — `ReportMarkdown(rep)`
- `comment.md` — `CommentMarkdown(rep, opts)`
- `authorship.json` — the attribution, indented
- `sessions/<harness>-<id>.json` — each session, indented (`id` with any
  character outside `[A-Za-z0-9._-]` replaced by `_`)

All free text rendered into Markdown passes through `redact.Text`.

## `ReportMarkdown(rep)`

```
# paircli report · PR #482: Add retry with backoff to webhook sender

**acme/shop** · `feat/retry` → `main` · 3 commits · 7 files · +210 −31
**Coverage:** 3 sessions (2 claude-code, 1 codex) · capture: hooked · 91% of changed lines explained · 1 unattributed commit

## Alerts

- **VER-2 Verification freshness:** 2 PR hunks were edited after the last passing test run (14:02 UTC).
  - `src/webhooks/retry.ts` lines 40-45 changed at 14:07 UTC, after the last passing run.
(… every signal with State alert, P0 first then catalog order; up to 3 alert findings each)

## What was actually asked for?

### INT-1 Ask ledger · □ derived · info

2 prompts across 1 session; first: “Add retry with backoff…”.

- (mid-task) cap at 5 attempts · `claude-code:ab12cd34` e7 · 14:10 UTC
- …

Support: claude-code full.

(… one `##` section per question in model.ReviewQuestions order, one `###` per signal)

## Not available

- **DEC-3 Decision trail:** LLM pass is off. Run with --llm to fill this in.

## Sessions

| Session | Link | Capture | Start | End | Models | PR lines |
|---|---|---|---|---|---|---|

## Commits

| Commit | Sessions | Method | Confidence |
|---|---|---|---|

Glyphs: ■ recorded · □ derived · ◇ inferred. Generated by paircli <version> at <GeneratedAt RFC3339>.
```

Rules:
- Question headings: intent "What was actually asked for?", authorship "Who
  wrote which lines?", verification "Was it verified, and does the proof still
  hold?", decisions "What was tried, rejected or corrected?", friction "Where
  did it struggle?", exposure "What else did this session touch?", oversight
  "How closely was a human watching?", consistency "Does the PR's story match
  the session's?". Skip a question with no signals.
- Signals with State `unknown` go only in "Not available".
- Finding lines: `- {summary}` + ` · {anchors as `file` lines}` + ` · {first evidence as `ref` event · clock}`;
  inferred findings (Provenance inferred) get a ` ◇` suffix. At most 15
  findings per signal, then `- … and N more in signals.json`.
- Session ids are shortened to 8 chars in text; SHAs to 7.

## `CommentMarkdown(rep, opts)`

```
<!-- paircli -->
**paircli** · 3 sessions (2 claude-code, 1 codex) · 91% of changed lines explained · capture: hooked

- ▲ **Verification freshness:** 2 PR hunks were edited after the last passing test run (14:02 UTC). `VER-2`
- ▲ **Test integrity:** … `VER-4`
- ◆ **Claim check:** 1 claims contradicted, 3 supported, 0 without evidence. `CON-1`
- ● **Start here:** Most rework: `retry.ts` (11 edits). Other files: 2 edits or fewer. `FRI-1`

<sub>Full report: `.paircli/pr-482/report.md`. Signals describe the change, not the author.</sub>
```

Rules:
- Line budget `opts.MaxCommentLines` (default 5) counts bullet lines only.
- Alerts first: signals with State alert sorted by Priority (P0 first) then
  catalog order; `▲` for recorded/derived, `◆` for inferred.
- Remaining budget, in order: FRI-1 when it has findings (`● **Start here:**`),
  OVS-1 (`● **Autonomy:**`), INT-1 **only when** `opts.IncludePrompts` (`● **Ask:**`).
- No alerts and no filler → `- No alerts.`
- No sessions → body is the marker line plus `No captured AI coding sessions matched this PR.`
- Never include finding text, prompt text (except INT-1 when allowed), or evidence.
